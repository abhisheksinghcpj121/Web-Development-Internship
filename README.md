## Projects

### Assignment 1 – Personal Profile Website

A basic personal profile website created using HTML. It contains personal information, skills, education, projects, favorite websites, daily routine and contact information.

**Technologies:** HTML

### Assignment 2 – PulseX Smartwatch

A modern and responsive landing page for the PulseX Smartwatch. It includes a navigation bar, hero section, features, specifications, pricing and contact/order section.

**Technologies:** HTML, CSS

### Assignment 3 – Interactive Personal Profile

An interactive personal profile website that allows users to enter personal information, select a favorite color, perform calculations and switch between light and dark mode.

**Technologies:** HTML, CSS, JavaScript
